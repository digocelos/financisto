## Journeys

### Build a reserve goal

Create Goal → Create Vault inside real account → Link Vault → Deposit funds → Review progress.

### Invest and track returns

Create investment account → Record contribution → Record dividend/JCP or return → Review balance/history.

### Use a goal for a purchase

Link purchase to Goal → Confirm paid principal → Progress increases by principal only → Interest remains separate.

## Phases

### Phase 1: Investments and vaults

**Milestone:** Members can create investment accounts, record movements and allocate money into Vaults within real accounts.

**Features:** Investment accounts; movements/returns; vaults and movements.

### Phase 2: Goals and progress

**Milestone:** Families can create Goals, link multiple Vaults, define contribution plans and see explainable progress.

**Features:** Goal configuration; goal-vault links; progress and history.

### Phase 3: Purchase integration

**Milestone:** Eligible financed purchases contribute paid principal once, without counting interest or vault settlement twice.

**Features:** Purchase-goal links; principal-only progress integration.
