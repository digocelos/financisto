# Encerramento com hard delete adiado

O encerramento solicitado pelo último Usuário bloqueia a Família imediatamente e inicia uma janela de recuperação de 30 dias. Após esse prazo, os dados da Família e seus vínculos são excluídos definitivamente; durante a janela, qualquer Usuário anteriormente vinculado pode reativá-la após novo login Google.
